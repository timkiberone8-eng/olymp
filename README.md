# Олимпиада KIBERone: интерактивные задачи

Сайт: https://timkiberone8-eng.github.io/olymp/

У каждой группы своя постоянная ссылка, она не меняется от недели к неделе:

- СБ 09:40: https://timkiberone8-eng.github.io/olymp/sb-0940/
- СБ 12:20: https://timkiberone8-eng.github.io/olymp/sb-1220/

На странице группы сверху задачи последнего занятия («Сегодня решаем», «Разбираем домашнюю»), ниже свёрнуты прошлые занятия. Кнопка «Показать QR» открывает код во весь экран для проектора.

## Звёзды

За каждую задачу до трёх звёзд. Обычная задача сразу даёт три, «Магические квадраты» по звезде за квадрат, «Волки и лисы» три за 9 переправ, две до 13, иначе одну. Демо-режим «Волков и лис» звёзд не даёт. Когда решены все задачи занятия, появляется надпись «Пройдены все».

Звёзды хранятся в браузере компьютера, отдельно для каждой группы, поэтому 09:40 и 12:20 на одних и тех же компьютерах друг другу не мешают. Внизу страницы группы есть «Начать заново на этом компьютере».

## Новое занятие

1. Новая задача: `python tools/add_task.py <файл из Antigravity>.html <slug>`. Скрипт кладёт её в `tasks/<slug>.html`, переключает Tailwind на локальную копию и подключает `assets/olymp.js`. Потом в коде задачи там, где она понимает, что решено, дописать `window.Olymp && Olymp.stars(3);` (или 1–2, если звёзды за качество). Кнопки «← Все задачи» (слева) и «Следующая задача →» (справа, по порядку занятия, у последней её нет) стоят внизу; если там что-то важное, у `<body>` задачи поставить `data-olymp-back="center"`, обе кнопки встанут по центру, как в «Волках и лисах».
2. В `data/groups.js` описать задачу в `OLYMP_TASKS` и дописать занятие в конец `lessons` нужной группы.
3. Закоммитить и запушить, Pages обновится за минуту.

Новая группа: скопировать папку `sb-0940` под новым именем, поменять в `index.html` `data-group`, добавить группу в `data/groups.js`, пересоздать `qr.svg` (`pip install segno`, затем `segno --scale 10 --border 2 --output <папка>/qr.svg "https://timkiberone8-eng.github.io/olymp/<папка>/"`).

Страница без группы, даты и разделов «Сегодня решаем» / «Разбираем домашнюю» (сейчас `zadachi/`): в `data/groups.js` у такой группы нет `name`, а у занятия вместо `today` и `review` один список `tasks`. `stars: false` у группы убирает звёзды: на карточке решённой задачи «✓ Решено», задача считается решённой, когда набрала бы все три звезды (у «Магических квадратов» все три квадрата). В общий список групп на главной она не попадает, ссылку даёшь сам.

Репозиторий публичный: ответы к домашним задачам, которые ещё не разобрали, сюда не класть.
